# Globe frontend

React, Vite, and Cesium. From this directory:

```bash
npm ci
npm run dev
```

The app opens at `http://127.0.0.1:4178`. Set `VITE_API_BASE` in `.env.local` if the API is not on `http://127.0.0.1:8091`. See the repository README and `globe/PUBLISH.md` for the API and publishing steps. `globe/LAYERS.md` covers the river and wind layers and the on/off buttons.
